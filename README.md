# Customer Churn Prediction

A machine learning project that predicts customer churn using a Random Forest classifier and the Telco Customer Churn dataset.

## Project Status

**Version:** 0.1 — Initial development

This project is part of my hands-on machine learning journey. The current focus is on building a complete classification pipeline, evaluating model performance, and understanding the trade-offs involved in churn prediction.

## Current Features

- Data preprocessing
- Categorical feature encoding
- Machine learning pipeline
- Random Forest classification
- Prediction threshold experimentation
- Confusion matrix and classification evaluation

## Dataset

The project uses the Telco Customer Churn dataset (`WA_Fn-UseC_-Telco-Customer-Churn.csv`).

The dataset contains customer information used to study whether customers discontinue a telecommunications service. Please consult the original dataset source and its terms before redistribution.

## Evaluation

The current experiment uses a Random Forest classifier with a prediction threshold of 0.65.

Results and evaluation methodology will be documented here after validation of the evaluation procedure.

## Tech Stack

- Python
- pandas
- scikit-learn

## Running the Project

1. Clone this repository.
